# Python Mini Projects

A collection of small Python projects I built while learning, moving from
core fundamentals (loops, functions, file handling, OOP) to data libraries
(NumPy, Pandas). Each script is standalone and runs from the terminal.

## Projects

| File | Description | Concepts |
|------|-------------|----------|
| `Project_1.py` | Rock-Paper-Scissors against the computer | random, dictionaries, conditionals |
| `Project_2.py` | Number guessing game (1-100) with higher/lower hints and attempt counter | while loops, random |
| `guessing_game.py` | Password guessing game with easy, medium and hard levels and letter-position hints | lists, string indexing, loops |
| `Fake_Headlines_Generator.py` | Generates random "BREAKING NEWS" headlines | random.choice, f-strings, loops |
| `Calculator_with_history.py` | Command-line calculator that saves, shows and clears calculation history | functions, file I/O, input validation |
| `Hotel_system.py` | Restaurant menu, order taking and formatted receipt | dictionaries, string formatting, validation |
| `bank_account_system.py` | Customer and Account classes with deposit, withdraw and balance checks | OOP, classes, composition |
| `daily_sales_amount.py` | Calculates tiered tax for 5 employees' sales, plus total and average | loops, conditionals |
| `numpy_array.py` | Creating NumPy arrays and converting data types | NumPy, dtype |
| `pan_project.py` | Bank client data: concatenating, merging and appending DataFrames | Pandas: concat, merge |

## Requirements
- Python 3.x
- NumPy and Pandas, only for the last two scripts:
      pip install numpy pandas
